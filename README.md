
# Sebuilder

Build Scratch Everywhere! from .sb3 files

## Installation

### Requirements

- Rust toolchain ([Download](https://rust-lang.org/tools/install/))
- Docker installation

### Install

```bash
cargo install sebuilder
```







## Examples

```bash
sebuilder --name myproject -d "This is a description" --author you  -s Project.sb3
```
