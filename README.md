
# Sebuilder

Build Scratch Everywhere! from .sb3 files


## Run Locally

Clone the project

```bash
  git clone https://github.com/turbotoad12/sebuilder.git
```

Go to the project directory

```bash
  cd sebuilder
```

Run the project

```bash
  cargo run -- --help
```

## Examples

```bash
  cargo run -- --name myproject -d "This is a description" --author you  -s Project.sb3
```
